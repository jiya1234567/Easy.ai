# SOP-05: Automated SMS Alert Engine

**Module:** SMS Alert Engine
**Tab in App:** 📱 SMS Alerts / Communications Hub
**Domain:** Automated Communications & Real-Time Dispatch
**Engine:** Twilio SMS API + OMEGA Alert Orchestrator

---

## 1. PURPOSE

Automated, context-aware SMS dispatch system that:
- Sends critical health alerts from biometric monitoring
- Delivers stock price breach notifications
- Dispatches weather emergency warnings
- Provides scheduled AI-generated health summaries
- Supports multi-recipient alert trees

---

## 2. INPUTS REQUIRED

| Input | Format | Source |
|-------|--------|--------|
| Recipient phone number | E.164 format (+614xxxxxxxx) | Settings |
| Alert type | Health / Finance / Weather / Custom | Trigger module |
| Alert body | Text (auto-generated by LLM) | AI generation |
| Twilio credentials | Account SID + Auth Token | `.env` file |
| Trigger conditions | Thresholds per module | Settings |

---

## 3. STEP-BY-STEP PROCEDURE

### Step 1 — Configure SMS Credentials
Edit `.env` file:
```
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=your_auth_token_here
TWILIO_FROM_NUMBER=+61400000000
TWILIO_TO_NUMBER=+61412345678
```

### Step 2 — Launch App & Navigate
```powershell
py -m streamlit run streamlit_app.py
```
→ Click **📱 SMS Alerts** tab

### Step 3 — Configure Alert Recipients
- Click **+ Add Recipient**
- Enter: Name, Phone Number, Alert Types subscribed to
- Set notification hours (e.g., 7am–10pm only)
- Click **Save Recipients**

### Step 4 — Set Alert Triggers
Configure per module:
```
HEALTH ALERTS:
  - SpO2 < 94%              → Immediate SMS
  - Resting HR > 120 BPM   → Priority SMS
  - HRV < 20ms overnight   → Morning summary SMS

FINANCE ALERTS:
  - Stock drops > 5% intraday  → Alert SMS
  - Regime flips RISK-OFF      → Strategy SMS
  - Earnings date T-1 day      → Reminder SMS

WEATHER ALERTS:
  - Cyclone category ≥ 2       → Emergency SMS
  - Severe thunderstorm        → Warning SMS
  - Air quality index > 150    → Health SMS

CUSTOM:
  - Enter your own trigger logic
```

### Step 5 — Test Message Dispatch
- Click **📤 Send Test SMS**
- Confirm receipt on phone within 10 seconds
- Check delivery status in dashboard

### Step 6 — Monitor Alert Log
- View real-time alert log in the dashboard
- Filter by: date, type, recipient, delivery status
- Export log: `reports/biometric_alert_log.json`

### Step 7 — AI-Generated Health Summary (Daily)
- Enable **Daily Digest** toggle
- Set delivery time (recommended: 7:00 AM)
- AI generates plain-language summary of last 24h
- Example output:
  ```
  "Good morning! Your health stats look stable.
   Average HR: 67 BPM ✅  SpO2: 98% ✅
   HRV trending up — good recovery from yesterday.
   Steps: 7,340 — 2,660 to reach your daily goal.
   No financial alerts overnight. DIS holding $96.
   Weather: Clear skies in Darwin today. ☀️"
  ```
